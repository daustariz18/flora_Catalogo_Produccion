# Catalogo Web PetalOps

Repositorio principal del proyecto **Catalogo Web PetalOps**.

## Estructura del repositorio

- `catalog-react-v2/`: Frontend principal (React + Vite + TypeScript).
- `catalog-api/`: Carpeta para lógica/API auxiliar.
- `img/`: Recursos de imagen del proyecto.

## Requisitos

- Node.js 20 o superior
- npm 10 o superior

## Ejecucion local (frontend)

1. Entrar al proyecto frontend:
   - `cd catalog-react-v2`
2. Instalar dependencias:
   - `npm install`
3. Levantar entorno de desarrollo:
   - `npm run dev`

## Scripts utiles (catalog-react-v2)

- `npm run dev`: Inicia servidor de desarrollo.
- `npm run build`: Genera build de produccion.
- `npm run preview`: Previsualiza build local.
- `npm run lint`: Ejecuta lint del proyecto.

## Archivos ignorados

Este repositorio **no sube** entorno virtual local ni secretos:

- `.venv/`
- `.env`
